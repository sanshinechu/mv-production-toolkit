# 影片製作 6 項基本原則

本文件是本專案影片製作規範的唯一正本，由使用者明確要求遵守。適用於 MV、教學影片及其他影片的腳本、畫面設計、剪輯、字幕與交件檢查。所有參與本專案的 AI 都必須先讀取本文件；委派工作或交接給其他 AI 時，也必須附上本文件路徑並要求遵守。

1. **字幕帶淨空**：畫面設計先預留字幕區，重要圖像、圖表、標示和其他文字不得侵入或被字幕遮擋；以實際輸出的畫面檢查。
2. **不印旁白原句**：畫面上的重點文字須提煉關鍵詞或搭配圖像解說，不把旁白整句再印在畫面上。正常的旁白字幕與歌詞字幕另計。
3. **數字要有出處**：涉及事實或統計的數字須有可追溯來源，保留來源名稱、連結或文件位置，並在適當畫面或隨附說明標示。自行計算須保留原始資料與算法；示例須標明為示例，不得編造數據或來源。
4. **清單逐項出現**：清單配合旁白與講解節奏依序出現，避免一次塞滿所有項目；已出現的項目可依理解需要保留。
5. **中文字級正確**：依輸出解析度與觀看情境設定標題、內文、字幕的字級及層級，確認繁體中文字型可正常顯示，無缺字、裁切、重疊或過小難讀；不得只以編輯預覽判定。
6. **交件前抽幀**：從最終輸出的影片抽取畫面，至少涵蓋開頭、結尾、各類版型、清單逐項出現及字幕密集處，檢查文字、字幕區、字級、排版與轉場附近畫面。發現問題須修正、重新輸出並複查；未實際抽幀檢查不得宣稱已通過。

## 交件檢查

- [ ] 字幕區沒有遮住重要資訊。
- [ ] 畫面重點文字沒有整句照印旁白（字幕除外）。
- [ ] 事實與統計數字的來源可追溯。
- [ ] 清單依講解順序逐項出現。
- [ ] 中文字級、字型與層級在實際輸出中清楚正確。
- [ ] 已抽查最終影片影格，並保留抽幀或檢查紀錄。

若某項不適用，交件紀錄應寫明原因；不得默默略過。若工具限制使檢查無法完成，須明確列出未完成項目。
