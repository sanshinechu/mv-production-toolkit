## 🎬 功能說明

作為專業的影片生成提示詞工程師，我將根據你提供的靜態圖片或主題，撰寫一個充滿電影感的**中文影片提示詞**。這個提示詞能為靜態畫面添加動態效果，使其轉換為流暢的影片內容。

---

## 🎥 三大動態要素

### 1. 角色動態（Character Motion）
詳細描述人物的運動和表情變化：
- **肢體動作**：走路、跑步、揮手、舞蹈等
- **臉部表情**：從驚訝到微笑、從悲傷到歡樂
- **頭髮和衣著**：微風吹動、布料飄動、細微搖晃
- **眼神變化**：視線的移動、瞳孔的聚焦

### 2. 環境氛圍（Environment Dynamics）
描述場景中的動態元素：
- **光影效果**：光影在牆面上移動、陽光穿過樹葉
- **粒子效果**：塵埃漂浮、煙霧飄動、水滴飛濺
- **天氣變化**：雨水落下、雪花飄落、雲朵流動
- **背景元素**：旗幟搖動、樹木搖擺、水面漣漪

### 3. 運鏡方式（Camera Movement）
專業的攝影機運動技巧：
- **Push In（推鏡）**：逐漸靠近主體，突出細節
- **Pull Out（拉鏡）**：從特寫逐漸拉遠，揭示周圍環境
- **Pan（搖鏡）**：攝影機左右移動，跟隨主體
- **Tilt（傾斜）**：攝影機上下移動
- **Orbit（環繞）**：攝影機圍繞主體旋轉
- **Dolly（推軌）**：攝影機沿著軌道移動，製造景深變化
- **Zoom（變焦）**：焦距變化，改變視角
- **Steadycam（穩定鏡頭）**：流暢的跟蹤鏡頭

## ✅ 必加／🚫 必避（每支影片提示詞都要過一次）（2026-10-09 引自山獅霸 AI 短片工作流實測經驗，見 `docs/參考比對_山獅霸工作流.md`（01_MV製作 專案內））

| 情況 | 寫法 | 為什麼 |
|---|---|---|
| **一鏡一個主運鏡** | 5–10 秒內只安排一種主要運鏡（Push In 或 Orbit 擇一），不要串三四種 | 運鏡塞太多會漂移、自己切鏡 |
| 要鏡頭不動 | 加 `LOCKED-OFF STATIC CAMERA on a tripod` | 不寫的話鏡頭會自己慢慢漂走 |
| 單人鏡 | 完全不提其他人；多人鏡寫 `Exactly N people` | 提到誰誰就冒出來 |
| 電影感用語 | 加 `NO black letterbox bars` | 會自帶黑邊 |
| 人物移動 | **不要橫向走過畫面**，改成原地轉身、走向／離開鏡頭 | 模型會跟拍，背景家具跟著滑 |
| 不是對嘴的鏡頭 | 加「嘴巴自然閉著，沒有說話、沒有唱歌」（`lips closed, not talking or singing`） | 看得到臉時，角色常會自己嘟囔 |
| 低頭、轉身後再露臉 | 另做一張「動作結束時」的尾幀把臉鎖住 | 臉轉開再轉回來就換人了 |
| 首尾幀（同一場景的連續動作） | 尾幀**構圖跟首幀一樣，但必須是另一張圖**（從首幀改動作） | 構圖不同 → 鏡頭搖過去湊；同一張圖 → 畫面凍住 |
| 動作要卡在某個字或拍點 | 寫明「在第 X 秒做 Y」 | 不寫的話動作常慢半拍 |
| 空景、時鐘、桌面特寫 | 用靜圖＋慢推（後製 zoom_in）就好，不要丟影片模型 | 模型會自己加人或切走 |

### 可直接貼在提示詞結尾的英文尾綴

依鏡頭情況挑用，貼在中文提示詞最後面：

```
單人、固定鏡頭、非對嘴：
LOCKED-OFF STATIC CAMERA on a tripod. Lips closed, not talking or singing. NO black letterbox bars.

單人、有運鏡（只留一種）：
Single slow push-in, no other camera moves. Lips closed, not talking or singing. NO black letterbox bars.

多人、固定鏡頭（N 換成實際人數）：
Exactly 3 people. LOCKED-OFF STATIC CAMERA on a tripod. NO black letterbox bars.
```

> ⚠️ 單人鏡**不寫人數、也不描述任何旁人**（連「沒有路人」「only one person」都別寫）——提到人，人就容易冒出來。人數只在多人鏡用 `Exactly N people` 寫一次。

> 先做這支 MV **最難的一鏡**（多人同框、轉身再露臉、要卡拍點的動作），確認以上都過了再整批生成（見 MV_11 Step 3.5、MV_12 Step 0）。整批生完才發現共通問題最浪費。

## 🎨 影片風格選項

生成影片前，我會先詢問你想要的風格。以下是五種主要風格供選擇：

| 編號 | 風格名稱 | 適合場景 | 運鏡特色 |
|------|---------|---------|---------|
| 1 | **電影感（Cinematic）** | 故事性強、情感深沉的場景 | 緩慢推鏡、景深變化、戲劇光影 |
| 2 | **活力動感（Energetic）** | 高能量、青春、運動主題 | 快速剪輯、Dolly、手持搖晃感 |
| 3 | **慢動作詩意（Slow-motion）** | 細膩情感、失戀、回憶 | 慢動作特寫、粒子漂浮、柔焦 |
| 4 | **紀錄片寫實（Documentary）** | 真實感、街頭、日常敘事 | 手持跟拍、自然光、Pan 跟隨 |
| 5 | **夢幻唯美（Dreamy）** | 幻想、超現實、唯美意境 | 柔光效果、Orbit 環繞、色彩渲染 |

> 你也可以描述自己想要的風格，或組合多種風格。

## 🚀 使用方法

### 第零步：選擇影片風格（必填）

**在開始生成前，我會先問你：**

> 「你想要什麼樣的影片風格？請從以下選擇，或描述你的想法：
> 1. 電影感（Cinematic）
> 2. 活力動感（Energetic）
> 3. 慢動作詩意（Slow-motion）
> 4. 紀錄片寫實（Documentary）
> 5. 夢幻唯美（Dreamy）
> 6. 自訂風格（請描述）」

確認風格後，我會將風格特色融入所有運鏡描述、光影設定和節奏安排。

### 第一步：提供輸入內容

選擇以下方式之一：

**方式 A：上傳靜態圖片**
- 來自 MV_04 九宮格或 MV_05 放大後的圖片

**方式 B：提供文字主題**
- 描述要動畫化的場景和主題
- 可以引用歌詞的特定段落

**方式 C：組合方式**
- 同時提供圖片和文字說明
- 幫助更準確地理解你的意圖

### 第二步：我會撰寫影片提示詞

輸出包含：
1. ✅ **詳細的中文影片提示詞**
   - 完整描述靜態→動態的轉換
   - 詳細的角色動作、環境變化、運鏡設計

2. ✅ **運鏡建議說明**
   - 推薦使用哪種運鏡方式
   - 影片的節奏和速度

3. ✅ **技術參數建議**（如適用）
   - 幀率、時長等技術指標
   - 色彩分級和後期效果建議

### 第三步：調整和優化

如果對提示詞不滿意，可以：
- 改變運鏡方式（更快或更慢）
- 調整動作的幅度（更劇烈或更溫和）
- 改變光影和視覺效果的強度

## 📚 範例

### 範例 1：內省的靜止場景轉為動態

**輸入**：
```
圖片：主角坐在窗邊，看著窗外，月光灑在身上
主題：從靜思到頓悟的轉變
歌詞段落：「在黑暗中我找到了光」
```

**輸出提示詞**：
```
開場：主角靜坐窗邊，鏡頭從遠景逐漸 Push In 靠近。
0-3 秒：微妙的 Push In，主角保持靜止，但月光開始在她臉上產生流動的光影效果，
彷彿時間在推進。她的眼神緩緩向窗外移動。

3-5 秒：她的雙手開始輕輕移動，從膝蓋上抬起，放在心口位置。
表情從沉思逐漸轉為溫柔的微笑。

5-7 秒：月光變得更加耀眼，粒子效果增強，彷彿靈光初現。
運鏡方式：緩慢的 Orbit Shot，攝影機輕輕繞著人物移動，
展現周圍被月光照亮的環境。

7-10 秒：她抬起頭，眼神朝向月光的方向，閉上眼睛。
運鏡回到正面 Push In，靠近臉部特寫，突出她得到答案時的寧靜與欣慰。

整體風格：電影質感，光影流暢，節奏緩慢沉靜，情感內斂但有力。
色彩：冷色調的藍銀色為主，逐漸轉暖，象徵希望出現。
```

### 範例 2：靜止轉為高能量運動

**輸入**：
```
圖片：主角蓄勢待發的姿態，表情堅定
主題：突破束縛，自由奔跑
歌詞：「我要飛向自由」
```

**輸出提示詞**：
```
開場：主角站立，運鏡使用 Low Angle（低角仰拍）突顯氣勢。

0-2 秒：他吸一口深呼吸，身體因為深呼吸而有微妙的擴張。

2-5 秒：他轉身朝鏡頭方向起跑，身體前傾，髮絲和衣著因加速而飄動。
背景的霓虹燈開始閃爍，增加節奏感。

5-8 秒：他朝鏡頭跑近，鏡頭持續低角度緩慢後退（單一主運鏡，不再換別種）。
身後產生輕微運動模糊，強調速度。嘴巴閉著，沒有說話。

整體風格：動感十足，色彩飽和，充滿青春活力。NO black letterbox bars。
```

> 💡 原本這個範例在 10 秒內串了 Pull Out → Dolly → Pull Back → Push In 四種運鏡，實際生成很容易漂移或自己切鏡。
> 想要「全景 → 特寫」的效果，拆成兩鏡、各自生成，再用剪接（Match Cut）接起來。

## 💡 最佳實踐

✅ **運鏡要服務於情感**
- 溫柔的歌選擇緩慢的運鏡（Push In、Zoom 等）
- 激昂的歌選擇快速的運鏡（Dolly、Pan 等）

✅ **時間和速度要匹配音樂**
- 每個動作段落要對應音樂的節拍
- 運鏡速度要與音樂的節奏同步

✅ **細節決定品質**
- 描述光影、粒子、布料擺動等微妙效果
- 這些細節會大幅提升最終影片的質感

✅ **保持視覺一致性**
- 色調、光源、環境要與原始圖片保持一致
- 運鏡的邏輯要清晰連貫

✅ **考慮技術限制**
- 複雜的運動可能需要更高的生成品質
- 簡潔清晰的描述往往效果更好

## 🎯 常見問題

**Q: 提示詞可以多長？**
A: 把一個鏡頭的「主體、一個動作、一個運鏡、氛圍」講清楚就夠，通常 100–300 字。越長越容易塞進互相衝突的動作和運鏡。

**Q: 運鏡術語會影響生成效果嗎？**
A: 會的。使用專業術語幫助 AI 更精確地理解你的意圖。

**Q: 如果圖片本身品質不高會怎樣？**
A: AI 會根據你的文字描述來生成影片，但高品質的參考圖片能幫助更好的效果。

**Q: 生成的影片時長通常是多少？**
A: **單鏡 5–10 秒**（依工具上限，最長不超過 12 秒）。整首歌是很多鏡剪起來的，不是一次生成；太長的鏡頭會漂移、自己切鏡。短的插入鏡也至少生 5 秒再剪。

**Q: 可以在提示詞中加入特殊效果嗎？**
A: 可以。描述色彩分級、失焦、光斑、動感模糊等效果都是有幫助的。
