歡迎使用 MV 製作工作流程導航！本指南將引導你完成從靈感到上傳的整個 MV 製作過程。

## 📋 完整工作流程概覽

一個完整的 MV 製作包括創意設計、素材生成、後期製作和發布：

| 步驟 | 模組 | 主要工作 | 工具 | 時間 |
|------|------|--------|------|------|
| 1️⃣ | **MV_01** 歌詞與曲風構思 | 創作歌詞、風格描述 | Claude | 30-60 分 |
| 2️⃣ | **ai-media-generator** | 用 SUNO 生成音樂 | SUNO 官網 | 30-60 分 |
| 3️⃣ | **MV_02** 主角造型設計 | 設計角色形象 | Claude | 20-40 分 |
| 4️⃣ | **MV_03** 影像提示詞生成 | 撰寫場景描述 | Claude | 20-30 分 |
| 5️⃣ | **MV_04** 九宮格分鏡設計 | 生成 9 張分鏡圖 | Claude | 30-45 分 |
| 6️⃣ | **MV_05** 截圖放大提質 | 選擇和放大重點 | Claude | 10-20 分 |
| 7️⃣ | **MV_06** 影片提示詞生成 | 靜態→動態效果 | Claude | 20-30 分 |
| 8️⃣ | **ai-media-generator** | 生成所有圖片和影片 | FAL 平台 | 5-30 分 |
| 9️⃣ | **MV_07** Q 版圖片設計 | 簡報或周邊插圖 | Claude+AI | 15-25 分（可選） |
| 🔟 | **MV_08** 空拍圖與運鏡生成 | 無人機視角和運鏡 | Claude+AI | 20-30 分（可選） |
| 1️⃣1️⃣ | **MV_09** Google Flow 微電影 | 首尾幀無縫轉場 | Claude+工具 | 25-35 分（可選） |
| 1️⃣2️⃣ | **MV_10** 電影感打光指令集 | 參考打光風格 | 參考表 | 自選 |
| 1️⃣3️⃣ | **MV_11** 時間軸分鏡腳本 | 依歌詞與能量切分鏡、標最難一鏡 | Whisper＋ffmpeg | 20-40 分 |
| 1️⃣4️⃣ | **MV_12** 分鏡批次生圖 | 先試 1–2 鏡，再整批生圖 | Cloudflare／Pollinations | 10-30 分 |
| 1️⃣5️⃣ | **組裝與自審**（本文件下方） | 剪接、響度、五遍自審 | ffmpeg | 30-60 分 |
| 1️⃣6️⃣ | **YouTube 發布工具** | 自動上傳到 YouTube | Python 腳本 | 2-5 分 |

> MV_11 + MV_12 是「Ken Burns 靜圖 MV」快速路線：歌曲 → 時間軸分鏡 → 免費批次生圖 → ffmpeg 組裝，
> 全程零生圖費用，適合校園歌曲、畢業歌等輕量專案。組裝用 `scripts/make_mv.py`（01_MV製作 專案內），範例素材見與 01_MV製作 同層的 `11_Opencode影片工作流/mv_project/`。

## 🚀 快速啟動

### 場景 A：完整 MV 製作（全流程）

**時間投入**: 約 4-8 小時（含等待生音樂、生圖、生影）

**步驟**：
1. 用 **MV_01** 創作歌詞和 SUNO 風格描述
2. 用 **ai-media-generator** 在 SUNO 生成音樂
3. 用 **MV_02** 設計主角造型
4. 用 **MV_03** 為場景寫影像提示詞
5. 用 **MV_04** 生成九宮格分鏡圖
6. 用 **MV_06** 轉換成影片提示詞
7. 用 **ai-media-generator** 批量生成圖片和影片
8. 用 **YouTube 發布工具** 自動上傳到 YouTube

### 場景 B：高效製作（推薦流程）

**時間投入**: 約 5-7 小時

**步驟**：
1. ✅ **MV_01** → 創作歌詞和風格
2. 🎵 **ai-media-generator** → SUNO 生成音樂（**並行等待**）
3. ✅ **MV_02~06** → 完成所有視覺設計
4. 🎨 **ai-media-generator** → 批量生成所有素材
5. 📤 **YouTube 發布工具** → 自動上傳並發布

### 場景 C：簡報或品牌素材製作

**時間投入**: 約 1-3 小時

**步驟**：
1. 用 **MV_02** 或 **MV_07** 製作 Q 版角色
2. 用 **MV_03** 撰寫視覺描述
3. 用 **ai-media-generator** 生成高品質圖片
4. 用 **MV_05** 截圖和放大重點
5. 完成設計並匯出

### 場景 D：特殊視角製作（高級）

**時間投入**: 約 2-4 小時

**步驟**：
1. 用 **MV_08** 生成空拍視角和運鏡指令
2. 用 **MV_09** 設計首尾幀無縫轉場
3. 用 **MV_06** 為轉場加入動態效果
4. 用 **ai-media-generator** 生成最終高品質影片

## 📚 各 Skill 模組詳細說明

### MV_01：歌詞與曲風構思
- **觸發詞**: `歌詞`、`作詞`、`曲風`、`SUNO`
- **主要功能**: 根據主題創作歌詞，為 SUNO 編寫風格描述
- **輸入**: 主題、曲風、情緒
- **輸出**: 完整歌詞 + 英文風格描述

### MV_02：主角造型設計
- **觸發詞**: `角色`、`造型`、`人物設計`、`主角`
- **主要功能**: 設計 MV 主角的視覺形象（英文+中文提示詞）
- **輸入**: 性別、曲風、歌詞內容
- **輸出**: Split Screen 的人物設計圖（臉部特寫+全身照）

### MV_03：影像提示詞生成
- **觸發詞**: `生圖`、`影像提示詞`、`畫面描述`
- **主要功能**: 生成詳細的中文影像提示詞
- **輸入**: 場景概念、主題、或圖片
- **輸出**: 中文影像提示詞（含構圖、場景、風格、鏡頭等細節）

### MV_04：九宮格分鏡設計
- **觸發詞**: `分鏡`、`九宮格`、`故事板`、`MV 分鏡`
- **主要功能**: 規劃 9 個鏡頭，**各自生成 9 張**單獨的分鏡圖（不是一張圖內含 9 格）
- **輸入**: MV_02 單張半身參考圖 + `[CHARACTER_REF]` + 主題描述
- **輸出**: `grid01`～`grid09` 9 張視覺一致的分鏡圖＋給人看的 3×3 總覽圖

### MV_05：截圖放大提質
- **觸發詞**: `裁圖`、`放大`、`提質`、`截圖`
- **主要功能**: 從 MV_04 的 9 張分鏡圖挑重點畫面（或裁出局部）放大
- **輸入**: 單張分鏡圖（grid01～grid09）
- **輸出**: 放大且提質的單張圖片

### MV_06：影片提示詞生成
- **觸發詞**: `影片提示詞`、`動態效果`、`運鏡`
- **主要功能**: 為靜態圖加入動態效果和運鏡描述
- **輸入**: 靜態圖片或主題
- **輸出**: 中文影片提示詞（含角色動作、環境變化、運鏡方式）

### MV_07：Q 版圖片設計大師
- **觸發詞**: `生圖`、`Q 版`、`插圖`、`簡報圖片`
- **主要功能**: 製作可愛的 Q 版插圖
- **輸入**: 簡報主題、角色、情緒
- **輸出**: Q 版插圖的提示詞 + 生成結果

### MV_08：空拍圖與運鏡生成
- **觸發詞**: `空拍`、`無人機`、`運鏡`、`Orbit`
- **主要功能**: 生成無人機視角，提供 Orbit/Push In/Pull Out 等運鏡指令
- **輸入**: 原始圖片 + 運鏡方式選擇
- **輸出**: 空拍視角圖片 + 運鏡指令

### MV_09：Google Flow 微電影製作
- **觸發詞**: `Google Flow`、`轉場`、`微電影`
- **主要功能**: 利用首尾幀製作無縫轉場效果
- **輸入**: 主題 + 角色類別
- **輸出**: 可直接使用的圖片和影片提示詞

### AI 多媒體生成器
- **觸發詞**: `生圖`、`生影片`、`AI 繪圖`、`Dreamina`、`FLUX`、`Kling`
- **主要功能**: 
  - 🎵 使用 SUNO 生成原創音樂（從 MV_01 的風格描述）
  - 🎨 生成高品質圖片（FLUX.1 或 Ideogram，$0.03-0.05/張）
  - 🎬 生成動態影片（Kling/Hailuo 快速版 或 Seedance 2.0 電影感，$0.07-0.30/秒）
- **使用時機**：
  1. 步驟 2：生成音樂（基於 MV_01 的 SUNO 風格）
  2. 步驟 8：生成所有圖片和影片素材

### MV_10：電影感打光指令集
- **觸發詞**: `打光`、`lighting`、`電影感`、`照明`
- **主要功能**: 提供 20 種電影感打光風格參考表
- **輸入**: 打光風格名稱或編號
- **輸出**: 英文指令 + 中文說明 + 視覺效果說明

### YouTube 自動發布工具
- **觸發詞**: `上傳 YouTube`、`YouTube 發布`、`上傳影片`、`批次上傳`
- **主要功能**：
  - 📤 單支上傳影片到 YouTube
  - 📋 批次上傳多支影片（用 CSV 控制）
  - 🎬 自動設定標題、描述、標籤、分類、隱私等
  - 📊 管理播放清單、查看頻道分析
- **使用時機**：步驟 13，發布最終 MV 到 YouTube
- **成本**：免費（YouTube Data API，有日配額限制 10,000 單位）

## 🔧 組裝與自審（上傳前必做）（2026-10-09 引自山獅霸 AI 短片工作流實測經驗，見 `docs/參考比對_山獅霸工作流.md`（01_MV製作 專案內））

先讀並遵守 `docs/影片製作基本原則.md`（01_MV製作 專案內）（字幕帶淨空、中文字級、交件前抽幀等 6 條）。

### 響度：兩段式（直接照抄）
```bash
ffmpeg -i mix.wav -af loudnorm=I=-15.5:TP=-1.5:LRA=11 -ar 48000 ln.wav
ffmpeg -i ln.wav -af ebur128 -f null -        # 讀最後的 I: 數值，gain = -15.5 - I
ffmpeg -i ln.wav -af "volume=<gain>dB,alimiter=limit=0.72:level=false" -ar 48000 final.wav
```
- **`alimiter` 一定要加 `level=false`**：預設會把輸出自動拉到 0 dBFS（爆音邊緣），**而且不會報錯**。
- 目標約 −15.5 LUFS、峰值 −2 dBFS 以下（YouTube 標準 −14，留一點餘裕）。
- 有口白段時，口白期間背景音樂壓到 15–30%。
- 同時輸出**手機版 720p（<30 MB）**，給老師、學生先在手機上看。

### 自審五遍（交給人看之前自己先審完、修完）

- **Ken Burns 靜圖路線**：`python scripts/review_mv.py <成片> --music <原曲>`（在 01_MV製作 專案根目錄執行） 會自動跑下表第 1、4、5 遍（另含分鏡加總＝歌長、畫面有沒有在動），讀 `make_mv.py` 的 STORYBOARD。第 2、3 遍與對拍還沒自動化。
- **其他路線**（雲端影片、Wan 等）：目前**用下表的 ffmpeg 指令手動檢查**，還沒有對應腳本。

| 遍 | 檢查 | 怎麼做 |
|---|---|---|
| 1 | 每鏡抽 4 格拼總覽圖，**逐張人工看** | ffmpeg `tile`；至少開一張原尺寸全幀 |
| 2 | 歌詞字幕跟實際唱的對不對得上 | MV_11 的 Whisper 時間戳、`subtitle-review` |
| 3 | 閃爍、油畫雜訊 | 跟該鏡首幀比 |
| 4 | 黑畫面、定格超過 0.8 秒、響度、峰值 | `blackdetect`、`freezedetect`、`ebur128` |
| 5 | 切點前後明暗跳、**切點有沒有落在 MV_11 指定的拍點** | 切點前後各抽一格並排 |

### MV 常退件清單
- [ ] 多手多腳、手指數不對
- [ ] 臉跟定妝照不像、前後鏡換人
- [ ] 背景冒出人、人突然消失
- [ ] 畫面出現亂碼字（黑板、招牌、衣服）
- [ ] 鏡頭自己漂走，或該動卻沒動
- [ ] 上下有黑邊（letterbox）
- [ ] 非對嘴鏡的角色自己在動嘴
- [ ] 切點沒對到拍子
- [ ] 歌詞字幕錯字或時間不對
- [ ] 字幕遮住重點畫面
- [ ] 響度忽大忽小、峰值爆音

### 原則
- **不合格就重做到合格**，不靠剪掉或插別的鏡頭躲。
- **技術檢查通過 ≠ 老師驗收通過**，兩個分開記；沒檢查的項目照實寫「沒查」。
- 給人看**並排影片或成片**，數字只當備註。

## ❓ 常見問題

### Q1: 我可以跳過某些步驟嗎？
**A**: 可以。根據你的目標，可以選擇需要的模組。例如只做簡報圖可跳過分鏡步驟。

### Q2: 每個步驟需要多長時間？
**A**: 取決於生圖/生影的速度。通常 MV 完整流程需要 3-5 小時（包含等待時間）。

### Q3: 用什麼工具生圖和生影？
**A**: 使用 `ai-media-generator` Skill（支援 FLUX.1、Ideogram 等）和影片工具（Kling、Hailuo、Seedance）。

### Q4: 如果對中間結果不滿意怎麼辦？
**A**: 可以重新執行該步驟的 Skill，調整提示詞或參數，直到滿意為止。

### Q5: 完成後如何上傳 YouTube？
**A**: 使用 `yt-auto-publisher` Skill 進行自動上傳和管理。

## 💡 最佳實踐

✅ **開始前**
- 準備好完整的主題和靈感
- 清晰定義 MV 的風格和受眾
- 列出關鍵視覺元素

✅ **執行中**
- 保存每個步驟的產出結果（圖片、提示詞等）
- 定期檢查視覺一致性
- 及時調整不滿意的部分

✅ **完成後**
- 檢查最終影片的品質和節奏
- 撰寫吸引人的 YouTube 標題和描述
- 分享到相應的平台並蒐集反饋
